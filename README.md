📊 Live Stock Market Dashboard

The Live Stock Market Dashboard is a real-time financial analytics application developed using Python, Streamlit, and Plotly. The dashboard provides live stock market insights by tracking Top Gainers, Top Losers, and Volume Leaders using real-time market data.

The application fetches live stock information from Yahoo Finance and analyzes stock performance based on percentage price changes and trading volume. Stocks with the highest positive returns are displayed as Top Gainers, while stocks with the largest negative returns are categorized as Top Losers. The system also identifies Volume Leaders by analyzing stocks with the highest trading activity.

Interactive visualizations and charts are created using Plotly, allowing users to explore market trends, compare stock performance, and monitor live trading activity in an intuitive dashboard interface. The application provides dynamic updates, graphical insights, and organized market summaries for better understanding of stock market movements.
